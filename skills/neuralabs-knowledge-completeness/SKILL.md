# Avaliar a completude do conhecimento

1. Defina o assunto e a referência de avaliação, como um capítulo, programa ou lista de objetivos. Quando o recorte vier de um edital, use a [skill de análise de editais](../neuralabs-edital-review/SKILL.md) para localizar os requisitos oficiais e suas páginas.
2. Consulte o índice `Projects/neuralabs-graph-<id>.md` por assunto e tópico. Abra só os conceitos e notas necessários para conferir a profundidade de cada item. Verifique sinônimos e conceitos compartilhados antes de classificar um item como ausente. Um título no índice é um ponto de partida para conferir o conteúdo.
3. Classifique cada item como bem coberto, superficial, ausente no recorte conferido ou não verificado. Dê o motivo e aponte a nota ou a fonte esperada. Se atribuir uma nota de 0 a 10 ao assunto, explique o critério e use apenas itens verificáveis no cálculo. Se a referência ou a amostra for insuficiente, apresente os achados sem nota global.
4. Entregue um resumo e uma tabela com item, situação e links para as evidências. A avaliação mede a cobertura do material no grafo. Para aprofundar um tópico ou preencher uma lacuna escolhida pelo usuário, encaminhe para a [skill de lacunas do grafo](../neuralabs-graph-gaps/SKILL.md).
