# Priorizar o estudo

1. Confirme o objetivo, a data-alvo e o tempo disponível quando forem relevantes. Use a prova ou o edital indicados. Se houver vários candidatos e a escolha mudar a prioridade, peça que o usuário indique qual usar.
2. Consulte no índice apenas os conceitos do escopo e os pré-requisitos necessários. Use a [trilha de aprendizado](../neuralabs-learning-path/SKILL.md) para interpretar a direção das dependências. Conte questões distintas com vínculo `TESTA` dentro da prova selecionada e use `COBRE` para verificar a cobertura do edital. Se o progresso local ajudar, consulte só as revisões ou tentativas pertinentes. Trate dados ausentes como desconhecidos.
3. Ordene os conceitos respeitando os pré-requisitos. Entre os que já podem ser estudados, priorize os sinais relevantes ao objetivo: incidência nas provas, exigência do edital e domínio ainda baixo. Se atualizar uma ordem anterior, conserve os itens que continuam válidos e destaque o que mudou e por quê.
4. Entregue na conversa uma lista curta para a próxima sessão. Para cada prioridade, inclua link para o conceito, motivo sustentado pelos dados e uma atividade concreta de estudo ou revisão. Se as evidências forem incompletas, apresente a ordem como sugestão. Quando o usuário pedir um plano persistido, use o fluxo de plano de estudo do NeuraLabs.
