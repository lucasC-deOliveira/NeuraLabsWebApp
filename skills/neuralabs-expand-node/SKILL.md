# Expandir um nó do grafo

1. Localize o nó no índice `Projects/neuralabs-graph-<id>.md`. Abra o Markdown do nó, os filhos diretamente relevantes e as fontes necessárias. Em grafos grandes, procure termos e sinônimos no índice para encontrar material reaproveitável antes de abrir outros arquivos.
2. Use o tipo do nó para escolher a expansão. Para `ASSUNTO`, sugira tópicos e seus conceitos. Para `TOPICO`, sugira conceitos. Para `CONCEITO`, sugira uma nota explicativa e cartões de prática. Para `NOTA`, prepare cartões pela [skill de flashcards](../neuralabs-flashcards/SKILL.md).
3. Para cada item, explique o que ele acrescenta, indique a fonte e mostre seu vínculo com o nó atual. Reaproveite nós equivalentes pelo ID. Em `PERTENCE_A`, o filho aponta para o pai. Prefira uma nota por ideia e preserve os links para os conceitos e fontes consultados.
4. Entregue uma prévia para o usuário escolher os itens. Prepare a inclusão de conceitos e notas pela [skill de grafo](../neuralabs-graph/SKILL.md) e a de cartões pela skill de flashcards. A criação de tópicos novos segue o fluxo existente do NeuraLabs. Valide os vínculos na prévia antes da gravação.
