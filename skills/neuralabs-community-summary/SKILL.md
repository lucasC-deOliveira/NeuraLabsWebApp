# Resumir uma comunidade do grafo

1. Identifique o grafo e o grupo. Se o usuário fornecer a seleção do painel de comunidades, use os IDs fornecidos para identificar os membros. Se fornecer apenas um tema, pesquise o índice `Projects/neuralabs-graph-<id>.md`, monte um recorte temático e identifique-o como tal.
2. Abra somente os Markdowns necessários. Em comunidades grandes, comece pelos conceitos centrais e por notas que expliquem suas relações ou aplicações. Amplie a leitura se faltar contexto para explicar uma conexão importante. Use os links confirmados no grafo selecionado, pois conceitos compartilhados podem ter conexões diferentes em outros grafos.
3. Escreva um resumo de estudo em Markdown, com um título e cerca de 200 a 500 palavras conforme o material. Explique como os conceitos se conectam e inclua um exemplo quando as notas derem base para ele. Vincule as afirmações principais aos nós de origem. Indique o recorte usado quando a leitura cobrir apenas parte da comunidade.
4. Entregue o resumo na conversa. Se o usuário pedir para salvar, use Markdown no vault. Se pedir para incorporar o resumo como nó ou criar relações, encaminhe para a [skill de grafo](../neuralabs-graph/SKILL.md) e gere a prévia antes de gravar.
