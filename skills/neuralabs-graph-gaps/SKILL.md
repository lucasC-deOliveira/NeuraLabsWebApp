# Investigar lacunas do grafo

1. Localize o grafo pelo índice `Projects/neuralabs-graph-<id>.md`. Para uma lacuna entre grupos, comece pelos nós de borda indicados no painel de lacunas ou pelo usuário. Para uma lacuna de cobertura, comece pelo item do edital ou pelo objetivo de estudo e pelos nós já ligados a ele. Leia apenas esse recorte.
2. Procure termos alternativos e confira as relações no grafo selecionado. Se encontrar uma ponte existente, mostre o caminho e explique o que já está coberto. Se a ausência de vínculo só puder ser verificada no recorte, declare esse limite. Para cobertura, identifique se falta um nó ou se o material existente precisa de aprofundamento.
3. Proponha a menor mudança que resolva a lacuna. Reaproveite nós por ID antes de propor novos conceitos ou notas. Para cada ponte, identifique os dois extremos, a direção dos vínculos e a evidência que ajuda a conectar os grupos. Para cobertura, cite o trecho da fonte e indique onde o conteúdo entraria.
4. Apresente as opções na conversa. Se o usuário escolher uma, prepare a prévia pela [skill de grafo](../neuralabs-graph/SKILL.md) para validar os tipos e as direções. Se a proposta incluir cartões, encaminhe-os para a [skill de flashcards](../neuralabs-flashcards/SKILL.md). Aplique mudanças após a aprovação da prévia correspondente.
